Add the Global Deep Sea Exploration Goals to Your Planning Tool

The 10,000 Global Deep Sea Exploration Goals and their 5 km exploration zones structured as a REST API you can query from any GIS application, ship planning system, or custom web map.

https://odl-exploration-goals-api.vercel.app/api/zones

Endpoints

All responses are GeoJSON FeatureCollection unless format=csv is requested. No authentication required.

GET /api/zones All 10,000 zones
Parameter Type Description Example
ocean string Filter by ocean basin North Pacific Ocean
mapped boolean Bathymetry mapped at ≥100 m false
depth_min integer Minimum depth in metres (positive) 2000
geomorph string Seafloor feature type Seamount
format string Response format geojson or csv
limit integer Max results (default 10000) 500
GET /api/zones/{id} Single zone by ID

Returns one GeoJSON Feature. Zone IDs follow the pattern OceanBasin-JurisdictionCode-Number — for example, North-Pacific-Ocean-HS-1234.

Add to your tool

The service speaks standard GeoJSON, so it works with any GIS application or web mapping library that can load a URL.

QGIS
  1. Open Layer → Add Layer → Add Vector Layer
  2. Set Source Type to Protocol: HTTP(S)
  3. Paste the endpoint URL into the URI field:
    https://odl-exploration-goals-api.vercel.app/api/zones
  4. Click Add. The layer loads as 10,000 point features you can filter, style, and query.

To load only unmapped seamounts: append ?mapped=false&geomorph=Seamount to the URL before adding.

ArcGIS Pro / Online
  1. In the Map tab, click Add Data → Data From Path
  2. Enter the endpoint URL and select GeoJSON as the type
  3. Click Add. The features appear as a temporary point layer.
  4. To make it permanent, right-click the layer → Data → Export Features to save to a geodatabase.

ArcGIS Online: use Add Layer → Add Layer from URL, paste the endpoint, choose GeoJSON.
